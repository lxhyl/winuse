Install安装

Two lines: one on the Windows PC, one on the machine your AI agent runs on.两行命令：一行在 Windows 电脑上，一行在 AI agent 所在的机器上。

1

On the Windows PC在 Windows 电脑上

PowerShell · Windows 10 / 11

irm https://winuse.ozlab.xyz/install.ps1 | iex

Finds or installs Python, sets up the winuse host with a logon task, and prints a token. Needs OpenSSH with key login.自动找到或安装 Python，装好 winuse host 和登录自启任务，最后打印令牌。需要 OpenSSH 密钥登录。

2

On your machine在你的机器上

macOS / Linux · Python 3.10+

curl -fsSL https://winuse.ozlab.xyz/install.sh | sh

Installs the winuse CLI, asks for the PC's SSH host and that token. Check with winuse status.装好 winuse 命令行，询问 PC 的 SSH 主机名和令牌。用 winuse status 检查。

Then point your AI agent at it: the winuse CLI, the Claude Code skill (… | sh -s -- --skill), or MCP (winuse-mcp).然后让你的 AI agent 用上它：命令行 winuse、Claude Code skill（… | sh -s -- --skill）或 MCP（winuse-mcp）。

Agent setup, remote installs and options接入 agent、远程安装与选项

Connect your agent接上你的 agent

Installing remotely, or irm hangs?远程安装，或者 irm 卡住？

PowerShell's own web client can stall forever on some networks. curl.exe ships with Windows and gives every fetch a time limit and retries; use this from an AI agent over SSH.在部分网络上，PowerShell 自带的网络请求会一直卡住。curl.exe 是 Windows 自带的，每次下载都有超时和重试；AI agent 通过 SSH 安装时请用这条。

powershell -NoProfile -Command "iex ((curl.exe -fsSL --retry 5 --retry-all-errors --connect-timeout 10 --max-time 60 https://winuse.ozlab.xyz/install.ps1) -join [char]10)"

Options选项

  • WINUSE_DIR — install folder (default C:\winuse)安装目录（默认 C:\winuse）
  • WINUSE_NOADMIN=1 — run the winuse host without admin rights不用管理员权限运行 winuse host
  • WINUSE_SOURCE_ZIP — install offline from a zip用本地 zip 离线安装
  • WINUSE_UNINSTALL=1 · install.sh --uninstall — remove卸载

Agents can reason and browse and script. The one place they go blind is the native desktop — the apps with no API. agent 会推理、会上网、会写脚本。唯一够不到的，是原生桌面——那些没有 API 的程序。

Browser tools cover the web. Shell covers scripts. But GUI-only installers, settings panels and legacy software have no other way in.浏览器工具管网页，shell 管脚本。但只有图形界面的安装程序、设置面板、老旧软件，没有别的入口。

winuse is the hands and eyes, not the brain. It reads the accessibility layer and acts in the background where it can — without moving your mouse or stealing focus while you work.winuse 是手和眼，不是大脑。它读取无障碍层，能后台就后台——你在用电脑时，不动你的鼠标、不抢你的焦点。

03

What makes it different与众不同之处

THE CORE IDEA

The GUI, as a text tree把界面读成文本树

Instead of guessing pixels, winuse hands your agent the accessibility tree: every control as a line with a stable reference like @e12. Cheaper than screenshots, and precise. Pixels are the fallback, not the default.winuse 不靠猜坐标，而是把无障碍树交给 agent：每个控件一行，带一个稳定引用，比如 @e12。比截图省 token，也更准。截图只是兜底，不是默认。

NON-INTRUSIVE

Acts in the background后台操作

Ref actions go through UI Automation — no pointer movement, no focus change, and they work even when the window is covered. Real input is refused while you're using the PC.对引用的操作走 UI Automation——不移动指针、不抢焦点，窗口被遮挡也能用。你在用电脑时，真实输入会被拒绝。

SCRIPT MODE

One call, many steps一次调用，多个步骤

winuse py (MCP run_python) runs a short Python script inside the winuse host: find, click, fill, verify, in one round trip. Only what the script prints comes back.winuse py（MCP 里是 run_python）在 winuse host 里跑一小段 Python：查找、点击、填写、核对，一次往返完成。只返回脚本打印的内容。

ANY AGENT

CLI · skill · MCP命令行 · skill · MCP

A plain CLI for shell-capable agents, a loadable skill for Claude Code, and a stdio MCP server for Codex, Cursor, Gemini CLI and the rest.给能用 shell 的 agent 一个命令行，给 Claude Code 一个可加载 skill，给 Codex、Cursor、Gemini CLI 等一个 MCP 服务。

SAFE BY DEFAULT

Localhost + token回环 + 令牌

The winuse host binds 127.0.0.1 only and checks a token. The sole remote path is your SSH key. No telemetry, ever.winuse host 只监听 127.0.0.1 并校验令牌，唯一的远程入口是你的 SSH 密钥。永不遥测。

ANY LANGUAGE

Unicode input任意语言输入

Typing is injected as Unicode, so Chinese, Japanese and emoji work regardless of the keyboard layout or IME.输入以 Unicode 方式注入，中文、日文、emoji 都不经过输入法，直接可用。

STAYS REACHABLE

Sleep & wake睡眠与唤醒

Prefer sleep over shutdown: winuse wake sends a magic packet and the signed-in session comes right back — no sign-in screen.优先睡眠而非关机：winuse wake 发一个魔术包，登录会话立刻回来，不经过登录界面。

04

Security model安全模型

Full desktop control means full trust: the winuse host runs elevated in your session and can do anything you can, PowerShell included. Here's exactly where the boundaries are.完全的桌面控制意味着完全的信任：winuse host 以管理员权限运行在你的会话里，你能做的它都能做，包括执行 PowerShell。这里讲清楚边界在哪。

01

Localhost only只听回环

The winuse host binds 127.0.0.1; nothing listens on the LAN. Remote access is your SSH tunnel — your key is the real boundary.winuse host 只绑定 127.0.0.1，局域网上没有监听。远程入口就是你的 SSH 隧道——密钥才是真正的边界。

02

Token on every call每次调用都带令牌

A bearer token readable only by Administrators and SYSTEM stops other local processes from using the winuse host.令牌只有管理员和 SYSTEM 可读，防止电脑上的其他进程借用 winuse host。

03

User-present guard用户在场保护

Real mouse and keyboard input is refused while you're actively using the PC, unless forced. Background actions don't touch the pointer.你在用电脑时，真实键鼠输入会被拒绝（除非强制）。后台操作则完全不碰指针。

04

No telemetry, no stored secrets无遥测，不存密码

Nothing leaves the machine. Typed text is never logged — only its length — and password fields are masked.没有任何数据离开本机。输入的文字从不记录（只记长度），密码框会被遮蔽。

05

Limits & FAQ限制与常见问题

Beta. Verified so far on one Windows 11 machine, single monitor at 100% scale, with the winuse host run as administrator; the one-line installer is verified there end to end, including run remotely over SSH. Designed for, but not yet tested on real hardware: multi-monitor, other display scaling, non-admin mode. No PyPI package yet: the installers fetch winuse from GitHub. Classic Win32 drop-down lists have no background route, so winuse briefly borrows the real cursor, then puts it back.内测版。目前仅在一台 Windows 11、单显示器 100% 缩放、winuse host 以管理员运行的机器上验证过；一键安装（包括通过 SSH 远程安装）也在这台机器上完整验证过。已按设计支持，但尚未在真机上测试：多显示器、其他缩放比例、非管理员模式。暂无 PyPI 包，安装脚本从 GitHub 获取 winuse。老式 Win32 下拉框没有后台通道，winuse 会短暂借用真实鼠标，用完放回原位。

Does it work on the lock screen?锁屏时能用吗？

No — when the session is locked the desktop isn't interactive, so winuse reports locked and refuses input (the guard is implemented; behaviour on the lock screen itself is untested). Prefer sleep over shutdown: a sleeping PC keeps its session and winuse wake brings it back with no sign-in screen.不能——会话锁定时桌面不可交互，winuse 会报告 locked 并拒绝输入（这层保护已实现，但在锁屏界面上的实际表现尚未测试）。建议优先睡眠而非关机：睡眠的机器会话还在，winuse wake 唤醒后直接可用，不经过登录界面。

Is it tied to one PC or vendor?只能用于某一台电脑吗？

No. The host, port and wake address are config, not code — point it at any Windows 10/11 machine you can reach over SSH.不是。主机、端口、唤醒地址都是配置而非写死的代码——指向任何你能通过 SSH 访问的 Windows 10/11 机器即可。

Can it play games?能用来玩游戏吗？

It's not built for that, and you shouldn't: injecting input into anti-cheat-protected games can get accounts banned. winuse is for productivity apps, settings and GUI tools.不是为此设计的，也不建议：向有反作弊的游戏注入输入可能导致封号。winuse 面向效率软件、设置和图形工具。

What about multi-monitor and high-DPI?多显示器和高 DPI 呢？

winuse is per-monitor DPI aware: screenshots, clicks and element positions are physical pixels on every monitor. winuse status lists the displays and their scale, and winuse shot --display N picks one. Verified on a single monitor at 100%; multi-monitor and other scaling are covered by unit tests, not yet by real hardware.winuse 按每个显示器分别感知 DPI：截图、点击和元素位置在每块屏幕上都是物理像素。winuse status 会列出各显示器及其缩放，winuse shot --display N 可以指定截哪一块。目前只在单屏 100% 缩放下实测过；多显示器和其他缩放比例只做了单元测试，还没在真机上验证。

Does the winuse host need administrator rights?winuse host 需要管理员权限吗？

By default it runs as administrator, so it can also operate elevated windows. Install with WINUSE_NOADMIN=1 to run it without: ordinary apps work as usual, but windows of programs running as administrator (Task Manager, regedit, elevated installers) are off limits. Windows blocks input from lower-privilege programs, and winuse says so instead of failing silently. winuse run commands then run without admin rights, and the host token is also readable by your user account. Non-admin mode is not yet tested on real hardware.默认以管理员身份运行，这样也能操作提权窗口。安装时设置 WINUSE_NOADMIN=1 可以不用管理员权限：普通程序照常可用，但以管理员身份运行的程序窗口（任务管理器、注册表编辑器、提权的安装程序）无法操作。Windows 会拦截低权限程序的输入，winuse 会明确告知，而不是悄悄失败。此时 winuse run 的命令不带管理员权限，令牌也能被你的用户账户读取。非管理员模式尚未在真机上测试。

Is winuse the agent itself?winuse 自己是 agent 吗？

No. It's the hands and eyes — the tools. Your AI agent (Claude Code, Codex, Cursor, …) does the reasoning and decides what to do.不是。它只是手和眼——是工具。思考和决策由你的 AI agent（Claude Code、Codex、Cursor 等）完成。
